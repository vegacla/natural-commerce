# Núcleo: comportamientos no evidentes

Observados al implementar el núcleo de MARCO. Fecha de cada uno entre paréntesis.

- **Lo leído del almacén trae más que el documento** (2026-11-18). `alm/leer` y `alm/buscar` devuelven también `:empresa` y `:nc/decision`, que agrega el almacén al escribir. Si se usa un documento leído como base de uno nuevo (modificar una entidad), hay que quitarlos: si no, la validación los toma por campos del tipo. `ejecutor/entidad-activa` lo hace.
- **Una entrada opcional no entregada vale nil, no falta** (2026-11-18). El resolvedor pone en `entrada` cada opcional ausente con valor nil (P4: ausente no es lo mismo que nil). Por eso `select-keys` sobre la entrada trae claves con nil, que pisan valores al hacer `merge`. Filtrar con `sin-nada` antes de mezclar.
- **Un tipo de Malli sin traducción se ve como `:cualquiera`** (2026-11-18). `validar/tipo-normal` traduce los tipos de contrato a los del validador y de SARA; uno que no conoce (pasó con `:keyword`) queda como `:cualquiera`, y SARA no sabe leerlo ni mostrarlo. La prueba `un-formulario-por-contrato` lo detecta.
- **Una política escrita en una prueba se cita** (2026-11-18). Las expresiones usan símbolos (`entrada/x`, `hecho/x`); en código Clojure, un mapa con ellos se evalúa y falla con "No such namespace: entrada". En los archivos EDN no pasa. En las pruebas, citar el cuerpo y la condición: `'{:valor [:* entrada/cantidad entrada/precio-unitario]}`.
- **Un mismo id puede aparecer en dos requisitos** (2026-11-18). Una entrada que no existe y una "fija" que rechaza su valor dejan dos requisitos con `:id :entrada/x`: uno con `:problema`, otro con `:razon`. Quien busca "el" requisito de una entrada debe mirar todos.
- **El 0 suelto hace de existencia vacía** (2026-11-18). `[:saldo concepto clave campo]` devuelve 0 si el saldo no existe, y `nc.valor` acepta el 0 en sumas, restas y comparaciones con cualquier valor. Así la disponibilidad de un producto que nunca entró a la bodega se calcula sin casos especiales.
- **El validador no acepta restar desde un 0 suelto** (2026-11-19). `[:- 0 x]` con `x` cantidad es "No se puede operar [:numero :cantidad]": el 0 es un número, no una cantidad. Para negar se escribe `[:* -1 x]`.
- **Una lista fija de archivos de prueba se queda atrás** (2026-11-19). El script de mutaciones tenía los archivos de prueba escritos a mano y no incluía `verbos-test`, que llegó después: sus mutaciones habrían salido como no detectadas. Ahora los toma de `test/nc`.
- **Una palabra clave no puede empezar con un dígito después de la barra** (2026-11-19). `:cuenta/1101` no se puede leer: "Invalid token". Las cuentas contables van como `:cuenta/c1101`. Afecta a cualquier código contable que se quiera usar como palabra clave.
- **Una división puede dar una fracción periódica** (2026-11-19). `nc.valor/dividir` con dos enteros da un `Ratio` de Clojure, como 222000/7, y `bigdec` no lo convierte: "Non-terminating decimal expansion". `redondear` divide con escala cuando recibe una fracción. Lo encontró el costo FIFO.
- **El script de mutaciones solo muta código** (2026-11-19). Recarga el namespace del archivo mutado; un archivo de datos (`resources/`) no tiene namespace, y las pruebas lo leen al cargarse. Para probar una política o un contrato, la mutación va en el código que la interpreta.
- **Un máximo puede ser un 0 suelto** (2026-11-19). Un concepto como la existencia libre da 0 (número) si no hay saldo, no `[:cantidad 0 :un]`. `nc.valor/numero` sobre ese 0 falla; para preguntar si un valor es positivo se usa `(pos? (v/comparar x 0))`, que acepta ambos. Lo encontró el límite parcial del planificador antes de correr.
